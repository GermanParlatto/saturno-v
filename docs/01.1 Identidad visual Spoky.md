# SPOKY — Character Sheet & Guía de Referencia Visual
## Proyecto Waku-Code · Documento complementario
### Identidad visual canónica + prompts de generación

---

## 1. Objetivo

Establecer la **identidad visual definitiva de Spoky** como referencia única para toda la producción de assets del proyecto Waku-Code (62 assets: cómics, videos, imágenes, GIFs).

Este documento cumple tres funciones:

1. **Fuente de verdad visual**: cualquier asset que se produzca debe ser contrastado contra la ficha de rasgos y la imagen de referencia canónica aquí definida.
2. **Banco de prompts**: los prompts en inglés están listos para copiar y usar directamente en los modelos de generación (Gemini Pro, Comicory, Seedance, Kling).
3. **Character sheet de producción**: las 4 vistas (frontal + 3 generadas) proporcionan las poses base que cubren los ángulos necesarios en cómics y videos.

---

## 2. Imagen de referencia canónica

**Archivo**: `spoky-frontal-canonico.png`
**Descripción**: Vista frontal, cuerpo completo, pose neutra, fondo blanco.

Esta es la **referencia principal** que se sube como imagen adjunta a todos los modelos de generación. Fue seleccionada por:

- Pose frontal neutra → máxima extracción de identidad por los modelos
- Fondo blanco/limpio → sin ruido visual que confunda al modelo
- Silueta completa → proporciones de cuerpo reproducibles
- Pixel grid uniforme → estilo replicable

## 3. Ficha de rasgos canónicos

| Rasgo | Descripción | Valor para prompts (inglés) |
|---|---|---|
| **Estilo** | Pixel art con bloques uniformes, sin anti-aliasing | `pixel art style, clean blocky pixels, no anti-aliasing` |
| **Color cuerpo** | Verde neón con sombreado verde más oscuro en extremidades y lados | `neon green body with darker green shading` |
| **Outlines** | Negro, gruesos, pixelados | `thick black pixel outlines` |
| **Ojos** | Grandes, oscuros (gris-negro), con highlights de cruz/estrella blancos en el centro | `large dark eyes with white cross-shaped highlights` |
| **Antenas** | **Ambas zigzag**, verde brillante, nacen de la parte superior de la cabeza | `two zigzag antennas, bright green` |
| **Proporciones** | Cabezón — cabeza ≈ 40% de la altura total del cuerpo | `chibi proportions, large head, small body` |
| **Extremidades** | Brazos y piernas cortos, terminan en formas redondeadas (sin dedos definidos) | `short limbs, rounded hands and feet, no defined fingers` |
| **Paleta de colores** | Máximo 5 colores: verde neón, verde oscuro, negro, blanco, gris oscuro (ojos) | `limited color palette: neon green, dark green, black, white, dark gray` |
| **Tamaño de pixel** | Bloques visibles y consistentes — estilo retro 16-32 bit | `visible pixel grid, retro 16-bit to 32-bit game style` |

### Regla de consistencia

El nivel de consistencia definido para el proyecto es: **reconocible con variaciones aceptables**. Esto significa:

- ✅ La paleta, proporciones, antenas zigzag y ojos con highlights deben mantenerse
- ✅ Las variaciones leves de pose, expresión y ángulo son aceptables
- ❌ No se requiere consistencia pixel-perfect entre assets
- ❌ No aceptable: cambio de color, antenas rectas, ojos sin highlights, proporciones realistas

## 4. Prompt base reutilizable

Este bloque de texto se **agrega al final de cualquier prompt** para anclar el estilo de Spoky. Es el "ADN visual" del personaje en formato de prompt:

```
Character: small neon green pixel art alien called Spoky.
Style: clean blocky pixels, thick black pixel outlines, no anti-aliasing,
visible pixel grid, retro game aesthetic.
Features: two bright green zigzag antennas, large dark eyes with white
cross-shaped highlights, chibi proportions (head ~40% of total height),
short limbs with rounded hands and feet, no defined fingers.
Color palette: neon green, dark green, black, white, dark gray.
```

**Uso**: copiar este bloque y añadirlo después de la descripción específica de la escena o pose en cada prompt.

outlines, neon green body with darker green shading, two zigzag

## 6. Prompts por contexto de producción

### Para Comicory (cómics multi-panel)

Al configurar el personaje en Comicory, usar esta descripción en el campo de character:

```
Spoky — Neon green pixel art alien with thick black blocky outlines.
Two bright green zigzag antennas on top of head. Large dark eyes
with white cross-shaped highlights. Chibi proportions: oversized
head (~40% of body height), small body, short rounded limbs.
Limited palette: neon green, dark green, black, white, dark gray.
Clean pixel grid, retro 16-bit game style. No anti-aliasing.
```

Subir `spoky-frontal-canonico.png` como imagen de referencia del personaje.

### Para Seedance 2.0 / Dreamina (videos)

Incluir en cada prompt de video como referencia de personaje:

```
@Image1 as main character. The character is a small neon green
pixel art alien with thick black outlines, two zigzag antennas,
large dark eyes with white cross-shaped highlights, and chibi
proportions. Maintain pixel art visual style throughout the entire
video. Retro game aesthetic with visible pixel grid.
```

Subir `spoky-frontal-canonico.png` como @Image1 en cada generación.

### Para Kling 3.0 (clips para GIFs)

Incluir en cada prompt de image-to-video:

```
Animate this pixel art character. Maintain the exact pixel art
style — no smoothing, no anti-aliasing, keep visible blocky
pixels throughout the animation. [DESCRIPCIÓN DEL MOVIMIENTO].
Loopable motion, 4 seconds.
```

Subir la vista de Spoky más relevante para la acción como imagen de referencia.

### Para Gemini Pro (imágenes estáticas)

Incluir el prompt base (sección 4) + descripción de escena. Siempre subir la imagen frontal canónica como referencia.
